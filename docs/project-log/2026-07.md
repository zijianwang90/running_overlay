### Replace FIT Auto-Matches Existing Videos

- Replacing a FIT file now recalculates existing media items' timestamp match
  status against the new activity and automatically places timestamp-matched
  videos on their camera-group timeline tracks when they do not overlap existing
  clips.
- Added a regression test for importing videos against the wrong FIT, then
  replacing the FIT and getting timestamp-aligned clips without a separate
  manual auto-match action.
- Verification: `./scripts/test.sh ProjectDocumentUndoTests/replacingFitAutoMatchesExistingTimestampedVideos`.

### Local Development Keychain Prompt Avoidance

- Added a default credential-store factory that keeps bundled app builds on the
  macOS Keychain but uses an in-memory OpenWeather credential store when the app
  is launched without a bundle identifier, such as `swift run RunningOverlay`.
- Added `RUNNING_OVERLAY_DISABLE_KEYCHAIN=1` as an explicit development escape
  hatch for local runs that should never touch Keychain.
- Documented the local-development behavior in `docs/development/persistence.md`.
- Verification: `./scripts/test.sh ProjectSettingsTests`.

### Interval HUD FIT Lap Classification Fix

- Updated FIT lap import to ignore zero-duration, zero-distance lap messages so
  Interval HUD Bar and Interval Timeline do not render phantom `0:00` cooldown
  segments.
- Refined interval workout analysis so mixed-distance work after a repeated
  interval set can inherit active semantics when its pace matches the detected
  work laps, with the following recovery lap kept as rest when a cooldown lap
  remains.
- Refined repeat detection to try alternate distance and duration candidates
  when the largest repeated-distance group does not produce separated work/rest
  intervals, covering short reps such as 200 m x 20 where recovery distances can
  be close to work distances.
- Added a guard against classifying ordinary paused auto-lap runs as structured
  intervals when duration-based candidates are just repeated long-distance laps
  with pause-stretched kilometers.
- Added synthetic parser and workout-structure regression tests. Verified with
  an optional local FIT sample without committing private activity data.
- Verification: `./scripts/test.sh FitFileParserTests`;
  `./scripts/test.sh WorkoutStructureAnalyzerTests`;
  `RUNNING_OVERLAY_INTERVAL_FIT_SAMPLE=/path/to/local.fit ./scripts/test.sh WorkoutStructureAnalyzerTests/parsesProvidedSlowIntervalFitSampleWhenAvailable`;
  `RUNNING_OVERLAY_NORMAL_FIT_SAMPLE=/path/to/local.fit ./scripts/test.sh WorkoutStructureAnalyzerTests/parsesProvidedNormalPausedFitSampleWhenAvailable`.
