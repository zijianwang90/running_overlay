# Project Log — November 2026

## 2026-11-01

### Resolve built-in templates as the configuration entry

- Replaced the Stack/Row/Grid layout choices with the Mac app's built-in Easy
  Run, Race and Interval Workout templates.
- Added `src/domain/templates.js`, shared by the control plane and panel, with
  each Mac template's element centers converted to Fusion's bottom-up axis.
- Choosing a template replaces the widget list, keeps shared instance identities
  and Fusion styling, and positions each metric from the template on the next
  update; duplicates and off-template widgets get deterministic free slots.
- Saved configurations without a template default to Easy Run. Tests cover the
  template inventory, exact positions, Lua generation and panel handlers; the
  reinstalled panel was host-checked on the independent validation project.

### Resolve interval components and workout classification

- FIT lap parsing now captures distance, elapsed time, average pace, heart rate,
  cadence, power and ascent; a JS port of the Mac analyzer classifies warmup,
  active, rest and cooldown laps and records workout structure.
- Added Interval HUD Bar (30), Interval Timeline (31), Interval Countdown (32)
  and Interval Work Summary (33) with phase labels, phase colors, time/distance
  remaining and progress, timeline segments/marker, ring countdown and
  completed-work summaries.
- Normalized lap statistics and structure in validation and the render TSV.
- Documented partial parity: HUD zone modes and metric slots, timeline windowing,
  summary max HR, per-role typography, glow and borders remain pending. Host
  validation used a synthetic five-lap workout; human review still required.

### Resolve lap data and Lap Pace

- FIT import now reads lap messages, converts lap ends to activity elapsed time,
  and interpolates each lap's starting distance from surrounding records.
- Added normalized lap validation (strictly increasing starts, non-decreasing
  distance), `lap` rows in the render TSV, and the Lap Pace metric (29) in the
  Fuse, mobile metric map and Workflow panel.
- Lap Pace renders `--` before a lap boundary, when the current lap has no
  distance, or when the activity has no lap messages (for example GPX).
- Documented partial parity: no manual laps, auto laps by distance, or lap
  history. Host validation rendered 5'41"/5'42" from a synthetic two-lap bundle;
  focused human review remains required for pace semantics.
