# Project Log — November 2026

## 2026-11-02

### Shared Skia GPU Overlay Renderer

- Replaced the preview-only SwiftUI path with one shared
  `SkiaEasyRunRenderer` for preview, export, and the editor helper. The
  renderer draws every supported overlay type in `layout.elements` order and
  uses Ganesh Metal for preview/export and the CPU raster bridge for tests.
- Ported the remaining overlay modules to Skia: numeric and decor text, route
  map, weather widget, distance timeline, running gauge, elevation chart,
  interval timeline, interval countdown, interval HUD bar, interval work
  summary, and zone edge bar. Each port ships with golden-frame tests against
  `SwiftUIOverlayVideoExporter.renderFrameCGImage`.
- Removed the SwiftUI preview fallback. In Debug builds, preview can render
  every overlay through the shared renderer via `RUNNING_OVERLAY_RENDERER=skia`
  or the preview header toggle, using a display link, paused scrubbing,
  backing-scale-aware resize, and an asynchronous MapKit snapshot preload
  outside the frame loop. SwiftUI remains the default until parity review.
- Added host preload contracts: layout, activity, canvas size, or available map
  snapshots change triggers preload; the one-time auto-preload in `draw` is
  only a safety net. Route and weather preload passes evict stale asset
  generations per family.
- Bounded per-frame caches: chart image cache LRU, icon and decor-text caches
  by count and bytes, and interval feather-mask cache by count and bytes.
  Animated SVG media slots now sample at 12 fps and pre-rasterize a finite
  frame grid instead of running AppKit image drawing per displayed frame.
- Preserved layout z-order in the SwiftUI export plan by batching only
  contiguous runs of numeric overlays.
- Recorded measured GPU throughput in ADR 0010: 1080p ProRes ~1.9x faster than
  SwiftUI export, 4K ProRes ~1.19x, 1080p preview ~119 fps, and 4K preview
  ~118 fps. HEVC alpha remains encoder-bound.
- Recorded the frozen bridge contract in
  `docs/superpowers/plans/notes/2026-11-02-skia-bridge-freeze.md` and module
  inventory notes for text, charts, intervals, and route. The Skia prebuilt is
  a development dependency only (`SKIA_DIR`); shipping it still requires the
  license/provenance entry called out in ADR 0010.
- Serialized Skia raster/Metal suites behind a process-wide test gate. Full
  runs had crashed intermittently in Skia's raster blur when several suites
  rendered concurrently, and AV export and shared UserDefaults fixtures raced
  across suites. The gate is test-only; production rendering is unchanged.
- Known limitations: pixel-level anti-aliasing and shadow shading differ from
  SwiftUI; goldens use changed-pixel and mean-delta thresholds rather than
  byte equality. The SwiftUI export layer still ignores `element.opacity`
  (pre-existing, unrelated to this migration). Ganesh is the only available
  Skia GPU backend; Graphite is deferred.
- Verification: `SKIA_DIR=... SKIA_GPU=1 ./scripts/check.sh` passed with 469
  tests in 55 suites. A gated re-run also passed.
