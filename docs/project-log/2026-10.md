# Project Log — 2026-10

## 2026-10-11

### Release-Build Export Profiling

- Headless benchmark commands now write export profiles in release builds, and
  profiles record `buildConfiguration`. Profiling schema is v6.
- Added `--profile-render-model` to `--benchmark-export` and
  `--benchmark-template-segments`. It times `OverlayRenderModel` layout
  evaluation separately before each unique render and records
  `renderModelDuration` per task, segment, and overlay.
- Fixed headless benchmarks that never exited when launched without a
  terminal: `NSApp.stop` now posts a wake event so the AppKit run loop
  returns.
- A release-build benchmark round showed that debug profiles overstated model
  cost about 90x, that HEVC-with-alpha 1080p export is bound by the hardware
  encoder (about 100 fps, unchanged by 2- or 4-process parallelism), and that
  ProRes 4444 full-frame exports spend most of their time redrawing reused
  frames. Details are in `docs/export-performance.md`.
- Verification: `./scripts/test.sh ExportPerformanceTests`;
  `./scripts/check.sh`; release and debug template-segments benchmark matrix.
