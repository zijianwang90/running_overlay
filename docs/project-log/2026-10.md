# Project Log — October 2026

## 2026-10-11

### Keep editor panes inside compact windows

- Fixed startup clipping caused by the preferred three-pane widths exceeding
  the 1300 pt minimum window width.
- Resolve side-pane widths from the available content width, preserve the
  Preview minimum, and bound divider drags by the remaining space. Retain
  preferred widths across window resizing and align the pool toolbar with
  the visible pane width.
- Explicitly enforce the scene content minimum size.
- Added regression coverage for minimum-width startup, enlarged side panes,
  divider limits, and restoring preferred widths on expansion.
- Validation: `./scripts/check.sh`, `./scripts/test.sh EditorPaneLayoutTests`,
  and `./scripts/visual-test.sh` passed. Built and visually checked the actual
  minimum-width app window in Media Pool and Overlay Pool modes. No visual
  snapshots changed.

### Packaged Resource Bundle

- Fixed SwiftPM app packaging to retain the complete resource bundle, including macOS-style bundle directory structure, so installed apps can find built-in templates, symbol names, and weather icons.
- Added a packaging regression gate that loads all required resources through Foundation `Bundle` and validates bundled JSON before signing.
- CI now builds the complete release app bundle rather than only the executable, so resource packaging is checked before merge.
- Verification: the resource validator rejects the malformed installed bundle and accepts the flat SwiftPM bundle layout; full app packaging additionally checks the macOS bundle layout.
