Running Overlay Studio **v0.1.5** (build **8**) is a stable release for macOS 15+.

This release adds GPX activity import, moves the editor into a single window
with an integrated toolbar, makes default exports about 1.5x faster, fixes
transparent exports that looked lifted in DaVinci Resolve, and restores
built-in templates in the downloadable app.

## Highlights

### Import

- **GPX activity import** - open timed GPX tracks alongside FIT files. GPS,
  elevation, common telemetry extensions, and derived distance, pace, and
  grade feed the same preview, alignment, and export paths. Lap structure and
  FIT-only running dynamics are not inferred from GPX.
- **Add Media appends** - importing more videos through the file picker keeps
  the existing Media Pool and timeline, matching Finder drops. Undo removes
  only the newly imported batch.

### Editor

- **Single-window editor** - the editor uses one window with a compact native
  toolbar.
- **Immediate playback seeking** - clicking or dragging the timeline ruler
  during playback jumps straight to the selected time and keeps playing.
- **Small-window layout** - side panes fit the actual window width, so the
  Preview and both side panels are no longer clipped at the minimum window
  size.

### Export

- **Faster exports** - default HEVC-with-alpha exports are about 1.5x faster
  and now limited by the hardware encoder. HEVC files are about 30% larger at
  the same bitrate, with a small alpha-quality trade-off. ProRes 4444 exports
  are also faster.
- **Clean transparency in DaVinci Resolve** - exported MOVs now carry BT.709
  color tags. Previously DaVinci Resolve could lift the background wherever
  the overlay clip covered the frame. For overlays exported with earlier
  versions, set the clip's Clip Attributes > Data Levels to Video.

### Packaging

- **Built-in templates restored** - the downloadable app packages its resource
  bundle intact again, so Easy Run, Interval Workout, and Race templates,
  symbols, and weather icons load correctly.
