Running Overlay Studio **v0.1.4** (build **7**) is a stable release for macOS 15+.

This release adds focused Interval workout overlays, separates project canvas
shape from output resolution, improves timeline selection and startup imports,
and makes completed exports unambiguous.

## Highlights

### Interval workouts

- **Interval Countdown** - add a compact circular countdown with configurable
  ring direction, time or distance center value, elapsed or remaining value
  direction, and per-role typography and visibility.
- **Interval Work Summary** - show a clear post-work-lap summary with one
  primary metric and up to three optional secondary metrics, each with
  configurable labels and text styling.

### Canvas and editing

- **Independent aspect ratio and resolution** - choose a landscape or portrait
  16:9, 4:3, or square canvas first, then select a compatible output size.
- **Timeline marquee selection** - drag across empty timeline space to select
  multiple clips and remove them in one undoable action.

### Import and export

- **Launch-file imports** - local debugging can open a FIT file with `--fit`
  and one or more source videos with repeated `--video` arguments.
- **Explicit export completion** - the editor toolbar replaces a completed
  `100%` progress indicator with a clear `Export Complete` confirmation.
