Running Overlay Studio **v0.1.3** (build **6**) is a stable release for macOS 15+.

This release tightens export resolution choices, improves Media Pool matching
feedback, and polishes the editor layout for template and timeline workflows.

## Highlights

### Export workflow

- **Orientation-safe resolution presets** — export resolution can still be
  changed, but presets now preserve the project's aspect orientation. Landscape
  projects only offer landscape export sizes, and portrait projects only offer
  portrait export sizes.

### Media Pool workflow

- **Match to existing layers** — Media Pool context menus now include a
  `Match to Layer` submenu so timestamp-matchable media can be synced directly
  to an existing timeline layer.
- **Clear status dot help** — hovering a Media Pool status dot now explains
  whether the item is ready to match FIT timestamps, already on the timeline,
  or needs manual placement.
- **Accurate status after deletion** — when a clip is removed from the
  timeline, the corresponding Media Pool item returns from green to the correct
  available/manual-placement state.

### Editor polish

- **Templates footer alignment** — the Templates footer now matches the Preview
  bottom playback bar height while keeping its buttons compact.
- **More room above the timeline** — the app starts with a shorter timeline
  split so the Media Pool, Preview, and Inspector panels have more initial
  vertical space.
