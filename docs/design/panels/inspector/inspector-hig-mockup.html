Inspector · HIG 设计稿

配套文档：inspector-hig-review.md。这份设计稿只调整控件层和交互模型， 不改动信息架构（分组、两栏布局、共享模块）。控件全部采用 macOS 系统控件的 .controlSize(.small) 外观，颜色全部是语义色（label、secondaryLabel、 separator、controlAccent）。黄色编号对应文档里的条目。

1 · Inspector Outer：列表

采用标准 List(selection:)。选中状态和 Preview、Timeline 同步；行内操作只在 hover 或非默认状态时显示；删除放进右键菜单并支持 ⌫。

4 · 度量

控件.controlSize(.small)：text field、pop-up、segmented 高约 20pt，checkbox 14pt，slider knob 13pt。
行属性行最小高 26pt（当前 34pt），列表行 28pt；section header 26pt。
文字标题 13pt semibold；标签 12pt secondaryLabel；数值 12pt .monospacedDigit()；不使用 10pt。
标签列保持 104–112pt，左对齐；子项缩进 12pt。
颜色label / secondaryLabel / tertiaryLabel / separator / controlAccentColor，保持深色外观，但自动跟随 Increase Contrast。
键盘Tab 在数值框之间移动；↑/↓ 调整数值；Esc 取消选择并回到列表；⌘[ / ⌘] 切换上一个、下一个 overlay。
