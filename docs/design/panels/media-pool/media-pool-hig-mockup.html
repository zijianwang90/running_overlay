4 · 控件对照

控件HIG 版本依据
列表
List(selection:) + OutlineGroup，保留斑马纹和 40pt 行高
 lists-and-tables、outline-views：键盘导航、焦点环、焦点相关的选中色
状态
Aligned　 Ready　 Manual
 color、accessibility：不要只靠颜色传达信息
搜索
Search⌘F
 search-fields：系统 search field，内置清除按钮，Esc 清空
状态过滤
AllReadyAligned
 segmented-controls：互斥选项用一个 segmented control；选中段跟随系统外观
Workout type
Intervals
 pop-up-buttons：互斥值选择显示上下箭头
Replace Activity
→ Replace Activity… / Show in Finder
 buttons：link 样式用于跳转，不用于替换数据
